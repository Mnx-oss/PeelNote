# PeelNote

PeelNote is a lightweight Windows desktop sticky-note app built around a simple idea: write on a note, peel it off, and keep it on your desktop.

## What it does

- Write directly on a small desktop note pad
- Peel notes into independent desktop windows
- Keep each peeled note's appearance frozen
- Collapse notes into compact strips
- Organize note history and saved items
- Use rich-text editing and images inside notes
- Keep the interface lightweight and stationery-like instead of turning it into a full knowledge-management app

## Download

The current packaged build is **PeelNote 0.1.19** for **64-bit Windows**.

Download the ZIP from the GitHub **Releases** page, extract it, and run `PeelNote.exe`.

## Status

PeelNote is a personal independent project and is still under active iteration. The current release should be treated as an early build rather than a finished commercial product.
